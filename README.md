Scientific Calculator

A clean, lightweight scientific calculator built with React.
This project is a simple, responsive calculator UI with common operations and a few scientific features — perfect as a small portfolio project or learning exercise.

Features

Basic arithmetic: +, -, *, /

Percent (%) and decimal point .

Toggle sign (±)

Clear (AC) and delete (backspace)

Evaluate expressions using JavaScript evaluation (fast and compact)

Minimal, easy-to-extend React component
